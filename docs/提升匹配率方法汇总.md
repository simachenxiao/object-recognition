## 一、✅ 有效方法（按收益排序）

### 1. 多形态描述法 —— 收益最大（§15/§16/§17/§18）

> **形态差异大的类别，必须分别描述它的每一种视觉形态。**

**诊断信号**：某类大面积误拒，看照片发现**图片本身长得五花八门**。

| 类别 | 原描述 | 没覆盖的形态 | 修复后 |
|---|---|---|---|
| **手机** | `["手机","智能手机","一部手机"]` | **背面**（8/11 是背面） | 2/11 → **11/11** |
| **钥匙** | `["钥匙","一串钥匙","一把钥匙"]` | **车钥匙遥控器**（6/16） | 7/16 → **16/16** |
| **手链手镯** | 只写「手链」 | **闭合圆环**（玉镯、金色粗环） | 4/7 → **6/7** |
| **指甲刀** | 只写「指甲刀」 | **闭合竖放的细长金属条** | 4/6 → **6/6** |
| **水杯** | 只写「水杯/保温杯」 | **细长圆筒** | 5/7 → **7/7** |
| **笔** | 只写「笔」 | **细长笔杆 / 笔夹** | 5/7 → **7/7** |
| **平板电脑** | `["平板电脑","平板","iPad"]` | **背面 / 横向** | 5/8 → **7/8** |

**写法示范**（§16 钥匙）：
```python
# ❌ 改前
["钥匙", "一串钥匙", "一把钥匙"]

# ✅ 改后 —— 传统钥匙 + 车钥匙遥控器两种形态都覆盖
["钥匙", "一串钥匙", "一把金属钥匙", "汽车的遥控钥匙", "车钥匙遥控器"]
```

**为什么有效**：一张手机背面的照片 = **一块矩形板 + 几个摄像头**，那正是充电宝的样子。
描述里没提「背面」，模型就把它当成充电宝。

### 2. 文字线索法 —— 把图上「真实写的字」写进描述（§25）

> **物品上印着的字，写进描述有效。**

| 类别 | 封皮上印的字 | 新增描述 | 效果 |
|---|---|---|---|
| 驾驶证 | 中华人民共和国 / **机动车驾驶证** | `封皮上的字是机动车驾驶证` | — |
| **行驶证** | 中华人民共和国 / **机动车行驶证** | `封皮上的字是机动车行驶证` | **2/3 → 3/3** |

**适用**：证件、包装、品牌、型号 —— 任何**图上有明确文字**的物品。

---

### 3. 对比式描述法 —— 类间差异必须成对写（§22）

> **当一个特征不属于某一类，而属于「类与类之间的差异」时，必须把两侧的描述成对地写。**

**来源**：用户的实际经验 ——「笔记本合盖不带摄像头但有 logo；平板有小摄像头带 logo；手机摄像头更多更大」

| 方案 | 笔记本 | 平板 | **错分** |
|---|---|---|---|
| 只加「没有摄像头的顶盖」 | 4/6 | 6/8 | 0（**无效**） |
| 只加「顶盖上只有一个品牌标志」 | 5/6 | 6/8 | **1** ⚠ |
| 加「宽大的长方形顶盖」 | 5/6 | 6/8 | **1** ⚠ |
| **两侧同时强化** | **5/6** | **7/8** | **0** ✓ |

```python
# 笔记本电脑：强调「没有摄像头 + 只有标志」
["笔记本电脑", "闭合的笔记本电脑", "没有摄像头的笔记本电脑顶盖",
 "顶盖上只有一个品牌标志的笔记本电脑", "笔记本电脑的金属外壳"]

# 平板电脑：强调「有一个摄像头 + 一个标志」   ← 必须同时加
["平板电脑", "平板", "iPad", "背面有摄像头的平板电脑",
 "平板电脑背面有一个摄像头和一个标志", "平板电脑背面的圆形摄像头"]

# 手机：强调「多个大摄像头」
["手机", "一部智能手机", "背面有多个大摄像头的手机", "细长的手机",
 "一部正面亮屏的手机", "手机背面的大摄像头"]
```

**为什么必须成对**：Chinese-CLIP 的判定是 **softmax 竞争**，不是绝对打分。
只强化一侧，只会让这一侧的向量靠近**所有「长得像」的图（包括别的类）**；
两侧同时强化，才能真正把**分界线**推过去。

**同类成功案例**（§23 打火机）：
```python
"打火机": [..., "带金属防风罩的打火机", "红色塑料壳的打火机"]   # 3/5 → 4/5
"电子烟": ["电子烟", "笔状的电子烟杆", "细长的电子烟", "带烟嘴的电子烟"]
```

### 4. 颜色区分同形证件（§18）

> **同形不同色的证件，颜色是强特征。**

| 证件 | 封皮颜色 | 描述 |
|---|---|---|
| **驾驶证** | **黑色 / 墨绿色** | `黑色封皮的驾驶证` `墨绿色封皮的驾驶证` |
| **行驶证** | **蓝色** | `蓝色封皮的行驶证` `一本蓝色的行驶证` |

修复前 4 张被拒，Top-2 全是对方（`驾驶证3.jpg` 0.589 vs **行驶证 0.411**）。
加上颜色后 93.5%。

### 5. 概念名优先 —— 别写视觉特征（§24，★反直觉）

> **描述要对齐「模型训练时见过的说法」，而不是「你眼睛看到的」。**

| 方案 | 描述 | **钥匙** |
|---|---|---|
| **A 概念名** | `汽车的遥控钥匙` `车钥匙遥控器` | **16/16** ✅ |
| B 概念名 + 视觉特征 | 再加 `一个黑色塑料的矩形遥控器` | 15/16 |
| **C 纯视觉** | `一个黑色塑料的矩形块` `带按键的黑色塑料遥控器` | **13/16** ⚠ |
| **D 纯视觉-极端** | `黑色的矩形塑料块` `上面有按键的黑色小方块` | **10/16** ⚠⚠ |

**原因**：
| 说法 | 训练数据里对应什么 |
|---|---|
| 「**车钥匙遥控器**」 | ✅ **大量真实车钥匙图** —— 有稳定、专属的图像分布 |
| 「**黑色塑料矩形块**」 | ❌ **没有稳定对应** —— 充电宝、遥控器、盒子、砖头、手机壳全是它 |

> **CLIP 的文本塔学的是「词 → 概念分布」，不是「词 → 视觉属性」。**

---

### 6. 去掉跨类重复的描述词（§20）

> **同一个词出现在两个类里 → 两类的文本原型互相污染。**

**实际发现的 bug**：
```
重复的描述词：「笔记本」 → ['笔记本电脑', '本子']
   笔记本电脑: ["笔记本电脑", "笔记本", "一台笔记本电脑"]
   本子:       ["本子", "笔记本", "一本记事本"]     ← 同一个词！
```
修复：两边都移除（本子改用「记事本」）。**建议每次改完配置都跑一次重复词扫描。**

---

### 7. 连带效应补偿 —— softmax 会重分配概率（§22/§23）

> **给 A 类加描述，可能压低 B 类的分数。**

| 场景 | 现象 | 补偿 |
|---|---|---|
| §22 强化平板/笔记本后 | `钱包8.jpg` 0.731 → **0.655**（跌破 0.70） | 加 `带拉链的皮质钱包` |
| §23 强化打火机后 | `指甲刀2.png` 0.742 → **0.694**（跌破 0.70） | 加 `小巧的金属指甲刀` |

**不是那些图变差了**，而是**别的类描述变强，softmax 把概率分走了**。
改一个类之后**必须全量回归**，看有没有别的类被压掉。

---

### 8. 概念名 + 简短视觉限定词（免费）

| 写法 | 效果 |
|---|---|
| `汽车的遥控钥匙` | 16/16 |
| `汽车的遥控钥匙` + `带按键的钥匙` | 16/16（**不伤**） |
| `汽车的遥控钥匙` + `黑色塑料的钥匙` | 16/16（**不伤**） |

**加简短视觉词是免费的** —— 但没有必要为了加而加。
**最稳的写法 = `概念名 + 视觉限定词`**，例如 `没有摄像头的笔记本电脑顶盖`。

## 三、❌ 试过但无效/更差的方向

| 方向 | 实测结果 | 出处 |
|---|---|---|
| **Few-shot 视觉原型**（图像均值，不训练） | 177/202 < 文本原型 190/202，**错分 9** | §21 |
| **kNN**（最近邻） | 171/202，**错分 18，误接受 2** | §21 |
| **相似度层面混合**（α·文本 + (1−α)·图像） | α=1.0（=纯文本）最优 | §21 |
| **换更大的模型**（ViT-L/14@336） | **误接受 0→2**，慢 9.2 倍 | §12 |
| **分层分类** | 无效，蚕食在组内 | §3 |
| **降阈值**（0.70 → 0.63） | 多认 1 张，但安全窗口只剩一半 | §19 |

### Few-shot 为什么输（§21）

| # | 原因 |
|---|---|
| 1 | **样本太少** —— 多数类只有 3~8 张，均值原型方差极大 |
| 2 | **类内方差大** —— 打火机 5 张含瘦长+宽扁两种；护肤化妆 4 张含口红+圆罐+圆盒+方盒，**均值是个四不像** |
| 3 | **打分尺度不匹配** —— 图图相似度集中在 0.1~0.6 窄带，套 `logit_scale=100` 过度尖锐 → 错分 |

**但它在特定类上确实赢了**（说明方向对，只是样本不够）：

| 类别 | 样本 | 文本原型 | 图像原型 |
|---|---|---|---|
| **笔记本电脑** | 6 | 4/6 | **6/6** ✅ |
| **钱包** | 8 | 7/8 | **8/8** ✅ |
| **本子** | 3 | 1/3 | **2/3** ✅ |
| 打火机 | 5 | **3/5** | 1/5 ⚠ |

**结论**：等每类 ≥20 张再上，或只在文本原型弱的类上单独启用。

## 四、诊断流程（怎么找到该改什么）

```
① 跑全量评测           check_accuracy.bat
        ↓
② 列出没满分的类        看「误拒 / 错分」分别是哪些
        ↓
③ 看照片 ★最重要★      拼对照图，找「这些图的共同点」
        ↓
④ 看 Top-3             被谁抢？抢的人是不是真的像？
        ↓
⑤ 设计描述变体          按上面的方法选一种
        ↓
⑥ 单项隔离测试          一次只改一个类，看 Δ总 和 该类别变化
        ↓
⑦ 全量回归              确认没错分、没压掉别的类
        ↓
⑧ 检查跨类重复词
```

### 关键诊断信号对照表

| 症状 | 根因 | 用哪个方法 |
|---|---|---|
| 某类大面积误拒，图长得五花八门 | 描述没覆盖形态 | **多形态描述法** |
| 某类被近邻抢走，Top-2 总是同一个 | 类间差异没写 | **对比式描述法** |
| 同形不同色的两个类互相抢 | 颜色没写 | **颜色区分法** |
| 证件/包装类识别不准 | 图上的字没写 | **文字线索法** |
| 某类分数就是上不去 | 描述用了视觉特征 | **概念名优先** |
| 改完 A 类，B 类掉下去了 | softmax 重分配 | **连带效应补偿** |
| 两类互相污染 | 描述词重复 | **删重复词** |

## 五、⚠️ 统计上必须注意的

**判断「加描述是否真的提升」必须看置信区间**：

```
本子          3 张   正确率 1/3   95% 置信区间 [6%, 79%]
   ← 改进到 2/3 → [21%, 94%]，区间完全重叠 → 统计上毫无意义
```

| 样本量 | 置信区间宽度 |
|---|---|
| 3 张 | ±40% 以上（结论不可靠） |
| 10 张 | ±25% |
| **20~43 张** | **±10~15%（可用）** |

> **这是补测试集的硬理由** —— 现在 33 个类里有 20 个不到 20 张。

## 七、一句话总纲

> **模型是现成的、免费的、离线可跑的。要提升匹配率，
> 不是去训练它，而是去「教会它你关心的那些东西长什么样」——
> 而教的方式，就是在描述里**枚举它可能出现的一切形态**，
> 并且**把类与类之间的区别成对地写清楚**。**
